


# 📝 Notepad

A simple and intuitive Notepad application built using HTML, CSS, and JavaScript,React. This Notepad app provides a clean and responsive user interface for creating, editing, and saving text notes directly in your browser.

## 🚀 Features

- **Create New Notes:** Start with a blank slate to jot down your thoughts.
- **Edit Existing Notes:** Easily update your saved notes.
- **Save and Load:** Store notes locally using your browser's local storage.
- **Responsive Design:** Optimized for both desktop and mobile devices.
- **Minimal and User-Friendly UI:** Clean and distraction-free interface.

## 🛠️ Technologies Used

- **HTML:** For structure and content.
- **CSS:** For styling and layout.
- **JavaScript:** For interactivity and local storage integration.

## 💻 Getting Started

### Prerequisites
To run this project locally, you only need a modern web browser.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/harshinis30/notepad.git
   ```
2. Open the project folder:
   ```bash
   cd notepad
   ```
3. Open the `index.html` file in your browser:
   ```bash
   open index.html
   ```
   or simply double-click the file.

## 📝 Usage

1. Open the application in your browser.
2. Type your notes in the text area.
3. Click "Save" to store your notes locally.
4. To load your saved notes, simply refresh or reopen the application.
